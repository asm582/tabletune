# Paper

[`paper.pdf`](paper.pdf), built from `paper.tex` (MLSys 2025 style files included) and its figures in `build/`.
After changing the source or a figure, rebuild with `bash docs/paper/build.sh` (Tectonic 0.17.0) and commit `paper.pdf`
with the change: CI fails a pull request whose PDF text differs from a fresh build, or that changes the sources
without the PDF. The fresh build is also uploaded as the `paper` artifact. The figures are regenerated by
`experiments/h100/analysis/figs_*.py` from the committed results; see [REPRODUCE.md](../REPRODUCE.md).
